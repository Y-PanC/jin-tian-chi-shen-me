# 今天吃什么 · 手机端 Web

当前基线版本：**v1.0.0**，定版日期：2026-10-25。版本范围、运行条件及资产说明见 [1.0 版本说明](docs/releases/v1.0.0.md)。

原生 HTML/CSS/JS 手机网页，390px 设计宽度，窄屏自适应。沿用紫、黄、棕色板和内联 SVG，正文独立滚动，底部胶囊导航固定可见。

首页、首次引导、问一问、推荐结果已接通。记一顿、我的、基本设置依据第七版可携包还原，并与推荐模块共享数据。

- 首页：当前目标、问一问入口、记一顿入口与横向健康饮食科普卡片。12 张科普卡片每次随机展示 4 张，一轮展示完前去重，并记住当前浏览器的展示历史。
- 首次引导：长期目标、口味、忌口、辣度、预算、饭量；上方步骤可点击切换并保留已选答案。新手完成后进入首页，从我的设置中编辑则返回我的。目标、辣度、饭量分别使用笔、辣椒、尺子图标。
- 问一问：当顿侧重、饮食方向、临时预算、换口味；上方步骤可点击切换并保留已选答案，仅用于本次。修改默认偏好统一从我的进入基本设置，多选题在题目后标注。
- 推荐结果：三份示例推荐、换一批、修改想法；先满足忌口、预算、辣度及上顿去重，再按决策表排序。
- 记一顿：文字为主，支持本地照片预览和设备听写提示；保存原文、日期和输入方式。最近饮食默认三条，展开后按日期浏览，也可修改已有记录。选中推荐只预填，点击记录后才保存。
- 我的：总餐数、早餐／午餐／晚餐时间范围、常吃菜品条形图、口味雷达图。
- 基本设置：昵称、选填手机号、照片／语音入口开关；保留长期饮食偏好编辑入口。退出仅清除本地昵称和手机号，保留饮食记录与偏好。

## 本地运行

当前默认使用本地打开模式。双击上一级目录的 `启动本地预览.command`，自动启动本地服务并打开浏览器；服务已运行时复用同一入口。

也可以在本目录手动启动：

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory dist
```

浏览器访问 `http://127.0.0.1:5173/`，需要 HTTP 服务读取 JSON 菜品库。

## 数据

`meal_logs` 是全站唯一饮食记录源。`assets/journal.js` 兼容现有 `dish/eatenAt/tags` 和第七版 `text/loggedAt/inputMethod`，写入时保留原文、标识、来源和附加字段。长期偏好使用 `user_profile`，界面设置使用 `user_settings`，职责不同，彼此不覆盖。

首次访问记一顿或我的时，只有从未存过 `meal_logs` 的浏览器会载入第七版的 30 餐虚构样例，界面明确标注。已有记录（含空数组）保持原样，清空后不会重建。来源说明见 [模拟数据说明](docs/meal-seed-sources.md)。

店铺和价格为演示数据；照片仅当次预览，不保存图像或上传服务器；语音入口依赖设备键盘听写，网页不录音。数据只保存于同一浏览器、同一来源。

页面路由和字段说明见 [接口说明](docs/interface-contracts.md)，推荐规则见 [推荐规则](docs/recommendation-rules.md)。
