# 今天吃什么 · 手机 Web v2.0

当前固定版本为 `2.0.0`，定版日期为 2026-10-25，Git 标签为 `v2.0.0`。前端为原生 HTML/CSS/JS，后端为 Python / FastAPI。账号、长期偏好、饮食记录、私有照片及画像统计均通过同源 API 保存和读取。v1.0.0 固定资产保持独立。

## 本地启动

首次安装：双击项目根目录的 `安装后端依赖.command`，需要 Python 3.11+。随后双击 `启动本地预览.command`。已有新版后端会复用；旧的纯静态 HTTP 服务需先停止。

入口：`http://127.0.0.1:5173/`。服务只监听本机，登录或注册后使用，保持启动窗口打开。不能再只用 `python -m http.server` 启动完整应用。

手动启动：

```sh
.venv/bin/python -m backend.run --no-browser
```

## 功能

- 六步长期偏好和四步当顿选择分别保存；顶部步骤可点击切换并保留当前答案。
- 推荐读取当前账号的实际餐食和偏好，沿用规则排序、预算/忌口过滤及换批去重。菜品、店铺和价格仍是演示目录。
- 记一顿支持多菜名、最多四张照片、标签、完整用餐时间和备注；年月日筛选和查看详情。
- 照片上传到后端私有目录，缩至最长边 1600px 并清除原 EXIF。上传后自动识别并填入可编辑的菜名和标签，保留识别期间的手动修改，保存餐食后才参与统计。
- 已配置的视觉服务使用 OpenAI Python SDK 的 Chat Completions 图片输入与流式输出。模型地址、密钥、模型名以及深度思考开关均在后端环境中配置。缺少配置、超时或识别失败时仍可手动记录。
- 我的展示累计菜品种类、记录餐数、记录天数、常吃食物和六维口味标签比例；由后端确认记录计算。
- 设置提供昵称、展示 ID、输入开关、长期偏好编辑和退出登录。内部账号 ID 与展示 ID 独立。
- 本机旧数据保留；在同一浏览器、同一 `127.0.0.1:5173` 来源的设置页手动导入记录。虚构样例自动排除，重复导入按原标识去重。
- 语音入口使用设备键盘听写，网页不录音。

## 数据和配置

本地默认使用 `.data/meals.sqlite3` 和 `.data/photos/`，均不在静态目录中；登录后的数据按用户隔离。服务端会话以 HttpOnly Cookie 保存，数据库仅保存令牌摘要。密码使用 scrypt 加盐散列。

复制 `.env.example` 为 `.env` 配置环境；`.env`、数据库、照片和虚拟环境均被 Git 与容器构建排除。不要把真实密钥写入前端、说明文档或版本归档。部署可切换 PostgreSQL，说明见 [后端运行与部署](docs/backend.md)。


## 固定版本

v2.0.0 的独立副本、ZIP 和 SHA-256 校验清单位于项目根目录的 `版本归档/v2.0.0/`。归档包含前后端源码、数据库迁移、依赖锁定文件、启动脚本和运行说明；模型密钥、账号数据库、私人照片和虚拟环境继续保留在本机，不进入固定资产。

当前为本地交付。Docker/PostgreSQL 部署文件已提供，Docker 容器和公网环境尚未实测。后续修改在工作目录继续进行，并使用新的版本号和归档目录；v1.0.0 与 v2.0.0 的固定资产和标签保持不变。
