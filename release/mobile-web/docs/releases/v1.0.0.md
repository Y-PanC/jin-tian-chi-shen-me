# 今天吃什么 v1.0.0

定版日期：2026-10-25（Asia/Shanghai）。这是当前手机端 Web 项目的固定基线，版本标签为 `v1.0.0`。

## 版本范围

- 首页：紫色决策卡片、放大的记一顿入口、固定底部导航与横向科普卡片；模块间距为 18px。
- 科普：12 张卡片随机组合，每批 4 张；一轮展示完前去重，下一轮避开上一批，展示历史保存在当前浏览器。
- 个人档案：六步引导，可点击顶部步骤切换并保留答案；首次完成进入首页，档案编辑完成返回我的。
- 问一问：四步当顿偏好，可点击顶部步骤切换并保留答案。
- 推荐结果：基于本地菜单和决策表的示例推荐、换一批与选中菜品。
- 饮食记录：文字记录、本地照片预览、设备听写提示、日期浏览和编辑。
- 我的及基本设置：饮食画像、统计、个人资料、输入入口开关与长期偏好编辑。

## 运行与数据

项目为原生 HTML/CSS/JavaScript 手机 Web，可通过 Python 3 启动本机静态服务，运行无需构建或安装第三方依赖。自动检查需要 Node.js。

开发目录继续使用 `http://127.0.0.1:5173/`，启动方式为项目根目录的 `启动本地预览.command`。页面与资源使用相对路径。

长期档案、界面设置、饮食记录和科普展示历史保存在浏览器中；当顿选择保存在会话中。归档保存项目文件和随项目提供的演示数据，个人浏览器数据仍留在本机。

这是前端功能演示版本：推荐来自本地规则和示例菜单；照片为临时预览，语音使用设备听写提示。服务端、账号同步、真实商家价格、图像识别和外部 AI 服务均不属于本版交付范围。

## 验证

在 `mobile-web/` 中运行：

```sh
node --test tests/*.test.mjs
```

定版时 19 项检查全部通过。近期浏览器验证覆盖步骤跳转及答案保留、科普随机去重、横向滚动和首页手机屏幕布局。

## 固定资产

完整资产位于项目根目录 `版本归档/v1.0.0/`：包含独立运行副本、源码和说明、自动检查、项目资料、预览图、文件校验清单及 ZIP 归档。

固定版副本使用 `http://127.0.0.1:5174/` 独立预览，启动说明以归档内《版本说明》为准。该地址拥有独立的浏览器存储；日常开发入口仍为 5173。

后续修改在现有开发目录进行。此基线通过版本标签、只读副本及 SHA-256 校验固定；新版本应使用新的版本号和归档目录。
