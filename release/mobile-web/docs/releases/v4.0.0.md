## 本次并入 v4.0 的修改

- 个人档案、首次引导和问一问统一使用九档预算：10元以内、10～15元、15～20元、20～30元、30～40元、40～60元、60～100元、100元以上、不限预算。预算步骤采用两列排列，不限预算位于底部并独占一行。
- 后端接收并保留新的预算区间标识，区分“100元以上”和“不限预算”；保留旧区间的读取兼容。旧档案在前端映射到相近的新档位，用户保存后才更新账号资料。
- 问一问的“不限类别”移至全部具体类别之后并独占一行，维持类别多选及与“不限类别”的互斥选择。
- 已有饮食记录在没有个人照片时，根据菜名、别名或菜品标识显示真实菜式参考图片；补充 10 张照片，结合现有图库覆盖旧版导入的 30 条示例记录。个人上传的照片优先显示，无法匹配的菜名保留原显示。精确菜名匹配优先于宽泛别名和旧菜品编号，避免炸鸡等记录配成汉堡照片。
- 最近饮食列表和餐食详情同步配图。详情中的参考图片可移除、更换，保存时沿用现有账号照片上传流程，重新打开后仍可显示。图库参考图片不重复触发照片识别。
