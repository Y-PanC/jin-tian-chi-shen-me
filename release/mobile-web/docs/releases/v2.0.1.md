# 今天吃什么 v2.0.1 · 开发记录

迭代版本：`2.0.1-dev`，已于 2026-10-26 合入 [v3.0.0 固定版本](v3.0.0.md)。开始日期：2026-10-25（Asia/Shanghai）。开发基线为 `v2.0.0`，提交 `60e2d2c431270a4f9d6beb71c2cd1d0e3046a803`。

## 2026-10-25

- 登录成功后统一进入首页；已有会话访问登录页也进入首页，登录页不再按旧的结果页等返回地址跳转。新账号仍需先完成长期偏好设置。
- 最近饮食卡片增加独立的删除图标，先确认菜名再提交；删除采用账号鉴权和版本校验，成功后更新列表、餐数和后续统计，失败时保留记录并展示错误。
- 本机旧记录导入可主动选择包含旧版示例，保留时间、菜名、备注、来源及原始标识；默认不包含示例。导入按账号和旧标识去重，并校验导入目标账号，账号切换时中止。
- 按用户要求，将浏览器保留的 31 条 v1.0 记录（含 30 条旧版示例）导入 pan，导入前备份本机数据库；已核对 31 个导入标识唯一，导入动作未覆盖原浏览器数据或 pan 的既有记录。
- 验证：前端 40 项、后端 27 项检查通过；浏览器验证实际登录后进入首页、独立删除入口、确认及取消流程、旧记录导入和统计读取。

v1.0.0、v2.0.0 的标签与只读固定资产保持不变；本轮继续在工作目录本地验证。

## 2026-10-26

- 推荐结果改为固定分页：每页最多三个候选，显示当前页及总页数，支持上一页、下一页和直接选择页码；同次推荐各页不重复，末页显示剩余候选。
- 按账号及本次答案、长期偏好保存推荐列表、页码和滚动位置；刷新、从餐食页面返回时恢复原画面，修改答案或偏好后生成新列表，退出或切换账号时清理。
- “选这份”进入餐食编辑后，返回按钮及放弃修改均返回原推荐页；推荐选项的草稿分开保存，切换菜品不会套用其他选项的未保存内容。
- 推荐结果页顶部增加返回箭头，回到“问一问”并回填本次已选答案；底部仅保留上一页和下一页。
- “问一问”改为类别、预算、配送时间三步：15 类常见外卖加不限类别、9 档预算、5 档配送时长；支持步骤切换和返回回填。新版答案同时筛选类别、预算上下界及预计配送时间，保留忌口、辣度和上顿同菜排除。
- 示例目录扩充至 50 道，为类别和各预算档补充候选，明确展示示例预计配送时长；暂未接入真实商家或配送服务。
- 本轮定向验证：问答选项与分页关联检查 14 项通过，浏览器验证三步选择、步骤切换、条件筛选及返回回填。
- 验证：前端 48 项、后端 27 项检查通过；浏览器覆盖上一页、下一页、指定页码、末页边界、刷新、页内返回、浏览器后退及放弃草稿，推荐内容和点击时的滚动位置一致恢复；320px 窄屏控件布局通过。

### 推荐展示与本轮问答

- 按《今天吃什么-v3.0文档.xlsx》“C组 1023 v1”规则与案例，将健康参考、口味匹配、单餐搭配、外卖适配和月售参考作为可查看的评分维度；按长期目标调节权重，结合真实历史作互补和重复修正，结果严格按综合分全局降序分页。健康分和推荐综合分分别展示，缺失销量明确保留为空。
- 菜品目录 56 道：保留文档六道菜的原始健康分、月售、外卖适配度和照片；原 50 道菜使用网上真实菜式参考照片，保留来源、作者、许可和近似菜式说明。全部通过本地相对路径加载，图片失败时明确显示缺图。
- 紫色顶部区域改为一句话推荐总结；每页卡片挑选不同的实际评分证据作为理由，完整五维明细与修正在“推荐依据”二级页面展示。返回推荐时恢复原页码与滚动位置；最近饮食变化会重新生成对应历史理由。
- 问一问类别改为多选，按类别并集筛选；按账号保留本轮已选答案、步骤和轮次。中途切页面、刷新、返回均可继续，推荐餐食成功保存后才清理对应轮；旧编辑页不能清理较新的选择。
- 常吃食物只展示 Top 3；设置页饮食偏好使用二级编辑界面，保存成功后直接返回设置，失败保留编辑页。
- 本轮仅修改前端与素材；40 项直接相关检查通过，覆盖评分核算、排序、多选、草稿、设置保存返回、兼容旧请求及结果恢复，未运行未改动的后端回归。
