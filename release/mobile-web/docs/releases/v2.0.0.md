# 今天吃什么 v2.0.0 · 固定版本

正式版本：`2.0.0`。定版日期：2026-10-25（Asia/Shanghai）。Git 标签：`v2.0.0`。

## 开发基线

从 v1.0.0 定版代码继续开发，基线提交为 `7546c1f093682ba4d7f880d7a3d1b2b1bc71741f`。v1.0.0 的版本标签、只读副本及 ZIP 作为独立资产保留。

本版本作为手机 Web 的固定基线，独立资产位于项目根目录的 `版本归档/v2.0.0/`。后续修改使用新的版本号和独立归档，不覆盖此版本及其标签。

## 本地运行

日常工作目录仍为 `mobile-web/`，入口为 `http://127.0.0.1:5173/`。登录后读取当前账号在后端的饮食记录和设置；旧浏览器记录保留，可从基本设置主动导入。归档的独立运行方式见包内《版本说明》。

## 功能完成与定版范围

- 本次固定范围为手机 Web v2.0.0，包含现有前端、Python 后端及前后端联调结果。
- 后端采用 Python，按可部署、支持多用户的 MVP 设计；账号、长期偏好、饮食记录、照片及统计由后端承接。
- 首批模型能力为照片识别：生成可编辑的菜名与标签草稿，由用户确认保存后纳入记录和统计。
- 模型适配采用 OpenAI Python SDK 调用格式，接口地址、模型名与密钥可配置；本机已按用户提供的信息接入百炼，部署平台待确定。未配置时保留手动记录流程。
- 推荐首期沿用现有规则，保留长期偏好与当顿选择的边界。
- 完成标准包括：多用户数据隔离、餐食新增与修改、照片上传与读取、识别成功／失败／未配置流程、日期筛选、统计联动、现有本地记录的迁移验证及部署说明。
- 小程序迁移排在手机 Web 版本完成并定版之后。

本次固定本地 Web 版本；供应商配置只在后端读取。Docker/PostgreSQL 配置随源码提供，容器运行和公网环境尚未实测，公网部署单独安排。
