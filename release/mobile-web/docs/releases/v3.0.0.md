# 今天吃什么 v3.0.0 · 固定版本

正式版本：`3.0.0`。定版日期：2026-10-26（Asia/Shanghai）。Git 标签：`v3.0.0`。

本版固定当前手机 Web 项目的前端、Python 后端、数据目录、图片素材、自动检查和运行文档。基于 v2.0.0 继续迭代，原始基线提交为 `60e2d2c431270a4f9d6beb71c2cd1d0e3046a803`；中间开发记录保留在 [v2.0.1 迭代记录](v2.0.1.md)。

## 功能范围

- 多用户登录及账号隔离；登录后统一进入首页。
- 长期饮食偏好与当顿问答分别保存。当顿问答分为类别、预算、配送时间三步，支持类别多选、预算上下界与时长筛选；中途切页、刷新和返回继续本轮选择，推荐餐食保存成功后完成对应一轮。
- 推荐结合长期目标、口味、忌口和实际饮食历史，按综合分降序分页；支持上一页、下一页、指定页码，跨页候选不重复，返回时恢复原页码和浏览位置。
- 56 道目录菜品配真实菜式参考照片；展示健康参考分、价格、预计配送时间、已知月售、标签及不同的具体推荐理由。顶部展示一句话总结。
- 推荐依据使用独立二级页面，展示健康、口味、单餐搭配、外卖适配、月售五个维度的原分、权重、折算分，以及目标和历史加减分、素材来源与许可。推荐卡片不显示“选择 01”等序号。
- 记一顿支持多菜名、最多四张照片、标签、用餐时间和备注，最近饮食支持年月日筛选、详情修改及确认删除。
- 照片上传后按 OpenAI Python SDK 兼容格式自动识别，填入可编辑的菜名和标签；保留手工修改，未配置或失败时可手动记录。
- 我的展示累计菜品种类、餐数、天数、常吃食物 Top 3 和六维口味画像。设置中的修改偏好使用二级页面，底部导航选中“我的”，保存后返回进入的设置页面。
- 本机旧记录通过设置主动导入，可明确选择包含旧版示例，按账号与原标识去重；原浏览器数据保留，不自动填充新账号。

## 运行与资产

日常工作目录为 `mobile-web/`，默认入口为 `http://127.0.0.1:5173/`。本地服务仅绑定回环地址。独立固定资产位于项目根目录 `版本归档/v3.0.0/`，包含源码副本、项目资料、运行脚本、ZIP、源码提交号、逐文件 SHA-256 清单、校验脚本及验收记录。独立副本从 ZIP 解压到可写目录后使用 5176 端口运行，方法见包内《版本说明》。

`.env`、`.data/`、`.venv/`、Git 内部文件、发布服务元数据与缓存不进入归档。账号、个人照片和模型密钥仍保留在原运行环境，恢复时单独配置或从个人备份恢复。

推荐在前端按规则计算；菜品、店铺、价格、月售、预计配送时间与评分为示例参考，照片为原始文档或公开菜式参考素材。单餐搭配按是否包含蛋白质、主食、蔬菜计算，暂不计算份量。照片识别需要另外配置视觉服务；本次定版未新增模型调用。Docker/PostgreSQL 配置随源码保留，容器与公网部署尚未实测。
