# 首页健康饮食科普来源

首页科普面向一般健康成年人，按《中国居民膳食指南（2022）》摘编。卡片池共 12 张，每次随机展示 4 张，并记录当前浏览器中的展示历史，优先展示本轮尚未出现的卡片。

- 蔬菜：每天不少于 300 克，深色蔬菜约占一半；使用西兰花图标。
- 水果：每天 200～350 克新鲜水果，果汁不能代替；使用苹果图标。
- 谷物：坚持谷类为主，经常搭配全谷物和杂豆；使用麦穗图标。
- 饮水：少量多次，优先白水或茶水，少喝或不喝含糖饮料；使用水杯图标。
- 奶类、鱼肉蛋、少盐和少油：分别使用奶盒、鱼、盐罐和油瓶图标。
- 早餐、三餐规律、食物多样和豆类：分别使用日出、时钟、餐盘和豆类图标。

来源：[国家体育总局《中国居民膳食指南（2022）发布——吃动平衡，养成健康生活方式》](https://www.sport.gov.cn/n20001280/n20001265/n20066978/c24291669/content.html)，核对日期：2026-10-25。卡片内容为一般科普，没有引用个人档案或推荐记录。
