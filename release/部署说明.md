# 今天吃什么 · v4 正常启动

功能基础版本 4.0.0，部署修订 4.0.0+deploy.2（2026-10-29）。

首次安装双击“安装后端依赖.command”，之后双击“启动本地预览.command”。或者进入 mobile-web/ 创建 Python 3.11+ 虚拟环境、安装 backend/requirements.lock，再执行：

```sh
.venv/bin/python -m backend.run
```

Windows 使用 `.venv\Scripts\python.exe -m backend.run`。默认端口 5177；服务只监听本机。

- 登录：http://127.0.0.1:5177/page_login.html
- 记一顿：http://127.0.0.1:5177/page4_log.html
- 我的：http://127.0.0.1:5177/page5_profile.html
- 设置：http://127.0.0.1:5177/page6_settings.html

正常启动会执行迁移，并自动创建 Yunzhong / 1234567890 和 33 餐历史。登录后即可查看记录、偏好和统计，无需手动导入。其他账号仍保持自己的数据。后续新增、编辑、删除不会被启动初始化覆盖。

数据统一保存在 mobile-web/.data/，配置在 mobile-web/.env。旧单独启动目录 .demo-data/ 在没有正常数据库、未指定数据库地址时自动复制迁移，源文件保留。更新代码前应关闭旧服务；后端会识别尚未更新的同端口服务并提示重新启动。

Docker 使用仓库根目录 README 的正常 `docker compose up --build -d` 步骤；后端默认执行同一初始化。需要 PostgreSQL 时见 mobile-web/compose.postgres.yaml。真实模型配置仅保存在 .env，不能提交 Git。
