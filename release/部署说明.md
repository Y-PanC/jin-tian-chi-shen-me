# 今天吃什么 · Web v4.0 本地运行

当前固定版本为 `v4.0.0`（v4.0，2026-10-27）。源码与独立运行包位于 `版本归档/v4.0.0/`，完整性校验及恢复方法见归档内《版本说明》。

工作目录当前固定版本为 `4.0.0`，包含预算统一、类别布局和已有记录真实配图。合并前的 v4.0.0 固定资产保存在 `版本归档/历史/v4.0.0_合并前_20261027/`；v1.0.0、v2.0.0、v3.0.0 与先前 v4.0.1 的历史快照保留。本地服务使用工作目录代码。

首次使用时双击 `安装后端依赖.command`，之后双击 `启动本地预览.command`。脚本启动 Python 后端并打开同源 Web 前端；服务只监听 `127.0.0.1`。

- 入口：http://127.0.0.1:5173/
- 记一顿：http://127.0.0.1:5173/page4_log.html
- 我的：http://127.0.0.1:5173/page5_profile.html
- 基本设置：http://127.0.0.1:5173/page6_settings.html
- API 文档：http://127.0.0.1:5173/api/docs

现在需要注册或登录，偏好、餐食与照片保存在后端。原浏览器的本地数据保持原样，可在相同浏览器和相同入口的“基本设置 → 本机记录”中手动导入。新账号不会自动填入虚构样例。

服务窗口保持打开，关闭窗口或按 Control+C 可停止。旧版纯静态服务不提供 API，需停止后重新启动新版服务。直接打开 HTML 文件会转到本机 HTTP 入口。

后端配置在 `mobile-web/.env`；数据库和照片默认在 `mobile-web/.data/`。密钥只供后端使用，文件不进入 Git 或镜像；版本打包时也须排除。

代码与联调说明见 `mobile-web/README.md`，Docker/PostgreSQL 与备份说明见 `mobile-web/docs/backend.md`。当前只在本机运行，公网部署需另行明确安排。
