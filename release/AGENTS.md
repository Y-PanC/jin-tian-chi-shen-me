# 项目与本地运行

- 前端源码：`mobile-web/dist/`；后端源码：`mobile-web/backend/`。自动检查：在 `mobile-web/` 运行 `node --test tests/*.test.mjs` 及 `.venv/bin/python -m pytest backend/tests -q`。
- 当前默认使用本地打开模式，入口为 `http://127.0.0.1:5177/`。
- 首次安装双击根目录的 `安装后端依赖.command`；双击 `启动本地预览.command`，启动 Python 后端和同源前端并打开浏览器；新版服务已运行时复用现有服务。纯静态 HTTP 服务不再提供完整功能。
- 本地服务只绑定 `127.0.0.1`，静态目录为 `mobile-web/dist/`，API 前缀为 `/api/v1/`。
- 后续修改默认只在本地保存和验证；公网发布需要用户明确要求。
- 日常迭代只检查本次修改和直接关联的流程，避免重复检查未改动的后端、页面和固定归档；版本定版、较大范围改动或相关检查失败时，再扩大检查范围。优先减少无关验证以加快开发。
- `github-pages/` 和 `mobile-web/.openai/` 保留历史发布文件与元数据。
- 所有页面路由和资源路径保持相对路径。页面使用 ES modules 和本地 JSON，统一通过本地 HTTP 入口打开。
- 登录后的饮食记录和设置保存在后端，账号隔离。本地默认数据库和私有照片目录在 `mobile-web/.data/`；生产可通过配置切换 PostgreSQL。
- 原浏览器数据保留，继续使用相同浏览器和 `127.0.0.1:5173`，从设置页主动导入；不得自动覆盖或清空旧数据，也不向新账号填充虚构样例。
- 模型配置只在后端环境中读取。`.env`、`.data/` 和 `.venv/` 不进入 Git、容器镜像或版本归档；真实密钥不得写入前端、日志和说明文档。
