## 使用固定版本

1. 保管好原始只读副本、ZIP 和外层 `SHA256SUMS`。从 ZIP 解压到新的可写目录作为运行副本，后续运行会在副本中创建环境和个人数据。
2. 安装 Python 3.11 或更新版本，在运行副本中双击 `安装后端依赖.command`。
3. 双击 `启动本地预览.command`，打开 `http://127.0.0.1:5175/`，保持终端窗口运行。
4. 注册或登录后使用。复制的是应用程序，账号数据库、私人照片和模型密钥需要在运行环境单独配置或从个人备份恢复。

固定版使用 5175 独立端口；日常项目入口继续使用 5173。首次运行生成独立数据库与照片目录，不会向新账号添加虚构记录。请通过本地 HTTP 服务打开页面。

手动启动（在 `mobile-web/` 目录）：

```sh
.venv/bin/python -m backend.run --port 5175 --no-browser
```

## 内容与配置

`mobile-web/` 包含与 Git 定版提交一致的源码、测试、文档、迁移和空配置模板。根目录另附启动/安装脚本、项目工作簿、验证记录、源码提交号、`MANIFEST.json` 和 `校验版本.py`。

`.env`、`.data/`、`.venv/`、Git 内部文件、发布服务元数据、缓存以及真实账号和照片不进入此资产。本机已有数据和密钥仍保存在原项目中。模型接口可在新副本 `mobile-web/.env` 中配置；详细字段见 `mobile-web/docs/backend.md`。

## 校验与恢复

在固定资产根目录运行：

```sh
python3 校验版本.py
```

该校验逐文件检查长度和 SHA-256；运行时产生的配置、数据库、照片、虚拟环境及缓存不参与源码校验。恢复 ZIP 时先核对外层 SHA-256，再在新的可写目录解压和校验。

运行副本可在 `mobile-web/` 中检查：

```sh
node --test tests/*.test.mjs
.venv/bin/python -m pytest backend/tests -q
```

前端 38 项、后端 25 项检查通过。记录见 `验证记录/`。源码也可通过原仓库的 `v2.0.0` 标签恢复。固定资产与标签保持不变，后续迭代在原工作目录使用新的版本号。
