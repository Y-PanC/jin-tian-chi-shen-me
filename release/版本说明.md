## 运行固定版本

1. 保存原始只读副本、ZIP 和外层 SHA256SUMS；先将 ZIP 解压到新的可写目录作为运行副本。
2. 安装 Python 3.11 或更新版本，双击 `安装后端依赖.command`。
3. 双击 `启动本地预览.command`，从 `http://127.0.0.1:5176/` 使用应用，保持服务窗口运行。
4. 注册或登录；账号、个人照片、模型配置需在该副本中单独创建、配置或从个人备份恢复。

本包独立端口为 5176，原工作目录日常入口继续使用 5173。两个目录使用各自的数据库和照片目录；新账号不自动填充虚构记录。请通过启动脚本和 HTTP 入口打开应用；源码 HTML 保留原工作目录的 5173 文件打开回退地址，不要直接双击 HTML。

手动启动（在解压副本的 mobile-web/ 目录）：

```sh
.venv/bin/python -m backend.run --port 5176 --no-browser
```
