## 运行固定版本

1. 保留只读副本、ZIP 和 SHA256SUMS，将 ZIP 解压到新的可写目录。
2. 安装 Python 3.11 或更新版本，双击“安装后端依赖.command”。
3. 双击“启动本地预览.command”，打开 http://127.0.0.1:5177/，保持服务窗口运行。
4. 创建副本账号，按需要单独配置模型或从个人备份恢复数据。

独立副本使用 5177 端口；原工作目录继续使用 5173，各自保存数据库和照片。不要直接双击 HTML，源码 HTML 的文件打开回退地址仍指向原工作目录 5173。

手动启动（在解压副本的 mobile-web/ 目录）：

    .venv/bin/python -m backend.run --port 5177 --no-browser
