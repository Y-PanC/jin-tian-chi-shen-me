## 打开固定版

1. 将整个文件夹保存在本机，保持目录结构完整。
2. 安装 Python 3 后，在 macOS 双击本文件旁的 `启动本地预览.command`。
3. 浏览器打开 `http://127.0.0.1:5174/`；终端窗口保持打开。

也可以从本文件夹手动启动：

```sh
python3 -m http.server 5174 --bind 127.0.0.1 --directory mobile-web/dist
```

固定版使用独立端口 5174，日常开发目录继续使用 5173。浏览器存储按网址独立保存，固定版首次访问会进入引导。个人饮食记录、档案和手机号等浏览器数据仍保存在原浏览器中。

## 资产内容

- `mobile-web/dist/`：完整前端网页、本地数据和 SVG 图标。
- `mobile-web/tests/`：19 项自动检查。
- `mobile-web/docs/`：页面接口、推荐规则、数据来源及版本范围。
- `项目资料/`：随项目提供的方案和设计文档。
- `预览图/首页.png`：定版时的手机端首页。
- `验证记录.txt`：从本副本运行自动检查的结果。
- `MANIFEST.json`：版本元数据及每个文件的 SHA-256。
- `校验版本.py`：核对固定版文件完整性。

## 验证和恢复

在本文件夹运行：

```sh
python3 校验版本.py
```

自动检查可在 `mobile-web/` 中运行：

```sh
node --test tests/*.test.mjs
```

完整 ZIP 与外层 `SHA256SUMS` 一同保管。恢复时将 ZIP 解压到新目录，再运行完整性校验。源码也可在原项目仓库通过 `git show v1.0.0` 或 `git worktree add <新目录> v1.0.0` 查看。

该副本和 ZIP 已设置为只读，后续开发请继续使用原项目目录，为新基线建立新版本。当前为前端功能演示，详细功能和服务边界见 `mobile-web/docs/releases/v1.0.0.md`。
