## 二、全局骨架（每个页面都必须一样）

```html
<body> 背景 --bg-outer，内容居中
  └── .phone（宽 390px，背景 --bg-page，min-height:100vh）
        ├── .page（flex:1，padding:0 20px 22px，可纵向滚动）
```

## 三、图标系统（最重要的一致性来源）

### 3.1 技术方案：内联 SVG 矢量图标库

- **只用内联 SVG**，禁止 emoji、禁止 PNG/JPG 图标、禁止 iconfont/第三方图标库。
- 每个页面 `<body>` 开头粘贴同一份 `<svg style="display:none">` 图标库（symbol 集合），用 `<use href="#i-xxx">` 调用。
- symbol 内部**不写 stroke 颜色**，统一由 CSS 的 `svg { stroke:... }` 或父级类控制，保证可换色。
- symbol 固定属性：`viewBox="0 0 24 24" fill="none" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round"`。

### 3.2 现有图标清单（直接复用，不许重画）

| id | 含义 | 默认颜色 |
|---|---|---|
| `i-home` | 首页 | 跟随所在组件 |
| `i-bolt` | 问一问（闪电） | 同上 |
| `i-camera` | 记一顿（相机） | 同上 |
| `i-user` | 我的（中性人像，圆形头+弧形肩，**无性别特征**） | 同上 |
| `i-noodle` | 面/主食 | 大卡内为 `--yellow` |
| `i-rice` | 米饭 | 知识卡内为 `--pink` |
| `i-chili` | 辣 | 同上 |
| `i-veg` | 蔬菜 | 同上 |
| `i-mic` | 语音 | 录入方式图标 |

**新增图标规则**：先查清单有没有；必须新增时，交给同一位同学画，保持 24×24 网格、1.6 线宽、圆头线帽风格。

## 五、版式铁律（Layout Rules）

1. **单栏竖屏**：设计宽度固定 390px，所有内容自上而下流式排列，禁止左右分栏（大卡内部的"左文右图"除外）。
2. **层级靠色块不靠线**：禁止分割线 `<hr>`、禁止卡片描边堆叠；层级用"紫 > 棕 > 白"三级色块表达。
3. **无阴影**：全项目 `box-shadow` 禁止使用。
4. **圆角偏大、直角为零**：任何矩形元素圆角 ≥ 14px。
5. **每屏只一个视觉主角**：大色块主卡一张，其余元素全部弱化（小、浅、白底）。
6. **emoji 禁止出现在 UI 里**（包括按钮、标签、说明文字）。
7. **图片使用**：除"记一顿"用户上传的照片外，界面不使用任何位图装饰。

## 六、交互与跳转约定

- 所有可点元素加 `cursor:pointer`，点击用 `location.href='页面名.html'` 跳转（演示原型不做动效）。
- 页面文件名固定：`page0_home_old_user.html`（首页）、`page1_guide.html`（首次引导）、`page2_ask.html`（问一问）、`page3_result.html`（推荐结果）、`page4_log.html`（记一顿）、`page5_profile.html`（我的档案）。
- 数据键名固定（localStorage）：`user_profile`、`meal_logs`、`demo_seeded`。
- 首次进入判断：`localStorage.getItem('user_profile')` 为空 → 跳 `page1_guide.html`。
