# 「今天吃什么」首页生成提示词

> 使用方法：把下面分割线之间的**全部内容**一次性粘贴给任意 AI，即可生成与标准稿一致的首页（单个 HTML 文件，浏览器直接打开）。

---

用纯 HTML + CSS + 少量 JS（不使用任何框架、不引用任何外部资源、不使用 emoji、不使用位图图片），生成一个 390px 宽的手机端 H5 页面：「今天吃什么」App 的**老用户首页**。所有代码写在一个 .html 文件里。

## 一、页面结构（自上而下，顺序固定）

1. **状态栏**：左侧"9:41"，右侧"信号 · 电量"，12px 灰色文字，两端对齐。
2. **顶部品牌行**：左侧品牌字"今天吃什么"（20px/700，其中"吃什么"三字为紫色 #7976AF，其余深色），右侧圆形头像按钮（34×34，浅紫底 #E9E6F4，内放中性人像 SVG 图标）。
3. **问一问大卡**（整卡可点击）：紫色 #7976AF 底、圆角 20px，左文右图。左侧：主标题两行"现在 / 决定吃什么"（24px/800，米白色 #F6F4FA，其中"吃什么"三字用蜜黄 #FFD361）→ 说明文字"当前目标：增肌，已结合你的档案"（12px，浅紫 #CDC9E2）→ 圆角按钮"问一问 →"（蜜黄 #FFD361 底、深棕字 #4A3A05、13px/700、圆角 20px、padding 10px 20px）。右侧：88×88 的面条碗线条图标，线条色 #FFD361。
4. **记一顿次卡**（整卡可点击）：尘棕 #B4816E 底、圆角 20px、padding 18px 20px。左侧：标题"记一顿"（16px/700，米白 #FAF3EE）+ 说明"拍照 / 语音 / 文字，随手记录"（12px，浅棕 #E3CDBF）；右侧：34×34 相机线条图标 + "→"（均 #FFD361）。
5. **区块标题行**：左"饮食搭配小知识"（15px/600），右"更多 →"（12px，灰紫 #9C96B5）。
6. **知识卡横滑区**：4 张白色小卡横向排列可滑动（gap 10px）。每卡：最小宽 118px、白底、圆角 14px、padding 12px，内部自上而下四行——22×22 线条图标（烟粉 #E39BBD）→ 卡标题（13px/600，深色）→ 两行说明（11px，#948DA8，行高 1.55）→ 来源标注（10px，#B4816E）。四张卡内容依次为：
   - 蔬菜叶图标｜"中午吃油了？"｜"晚上补深色蔬菜，清淡主食收尾"｜"来自你的档案：昨天吃了黄焖鸡"

   - 辣椒图标｜"想吃辣的时候"｜"选香辣不选麻辣，配无糖豆浆解辣"｜"通用小知识"

## 三、硬性禁令

- 禁止阴影（box-shadow）、禁止渐变、禁止分割线
- 禁止 emoji、禁止任何图片文件图标
- 禁止使用色板之外的任何颜色。色板全集：#7976AF #FFD361 #B4816E #E39BBD #E4E1EE #F6F4FA #39314A #948DA8 #9C96B5 #A79FB9 #BDB7CD #FFFFFF #E7E3F0，以及五个补充色：头像底 #E9E6F4、大卡说明 #CDC9E2、次卡标题 #FAF3EE、次卡说明 #E3CDBF、按钮字 #4A3A05
- 字号只允许出现：10 / 11 / 12 / 13 / 15 / 16 / 20 / 24 px

## 四、图标实现方式（必须照做）

用内联 SVG symbol 图标库：在 body 开头放一段 `<svg style="display:none">`，里面每个图标是一个 `<symbol>`，统一属性 `viewBox="0 0 24 24" fill="none" stroke-width="1.6" stroke-linecap="round" stroke-linejoin="round"`，symbol 内部**不写颜色**；使用时 `<svg><use href="#i-xxx"/></svg>` 调用，颜色由 CSS 的 stroke 控制。需要的图标 id：i-home（房子）、i-bolt（闪电）、i-camera（相机）、i-user（中性人像：圆形头+弧形肩，无性别特征）、i-noodle（面条碗）、i-rice（米饭碗）、i-chili（辣椒）、i-veg（蔬菜叶）。线条风格保持简洁手绘感、圆头线帽。

## 五、交互（简单实现）

- 问一问大卡、记一顿次卡、头像、导航各 tab 点击时用 `location.href` 跳转（目标文件名随意，如 page2_ask.html，演示用）。
- JS：读取 localStorage 的 `user_profile`，若其中 goal 字段存在且不为"不设"，把大卡说明文字替换为"当前目标：{goal}，已结合你的档案"；读不到就保持默认文案。
